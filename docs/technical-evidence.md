# 行情与安卓后台能力核验

核验日期：2026-09-11。以下是官方文档核验，尚未进行真实行情请求、付费账号验证或安卓真机测试。价格与接口权限以实际开通时为准。

## 1. AKShare：可作为验证候选，不能据接口名称承诺实时稳定

| 接口 | 文档确认的能力与边界 |
| --- | --- |
| `stock_zh_a_spot_em` | 东方财富沪深京 A 股行情快照，单次返回全市场；成交量单位为手、成交额为元。 |
| `stock_zh_a_hist` | 指定股票的日／周／月历史行情，支持不复权、前复权、后复权；当日收盘价需收盘后获取。 |
| `stock_zh_a_hist_min_em` | 支持 1、5、15、30、60 分钟；仅近期数据，其中 1 分钟只覆盖近 5 个交易日且不复权。示例还注明历史分钟开盘价可能为 0。 |

来源：[AKShare 股票接口文档](https://akshare.akfamily.xyz/data/stock/stock.html)。

**方案推论**：快照、历史 K 线、分时应分开接入；不能把快照请求成功理解为完整分钟历史已具备。对 0 开盘价等异常需校验并标记，不能直接生成正常 K 线。文档所述“实时”不等于已验证刷新间隔、延迟或可用性保证。

**接入前实测**：部署网络下的成功率、请求耗时、数据实际时间、可接受轮询频率、缺失字段与股票覆盖；抽样对照复权和分钟数据；确认目标使用方式的数据授权边界。尚不承诺免费数据源可长期稳定支持盘中预警。

## 2. Tushare：历史与实时权限要分别评估

- 普通数据按积分门槛开放，分钟、实时日线、新闻和公告等存在独立权限，不能用普通积分额度推定全部可访问。[权限与频次表](https://tushare.pro/document/1?doc_id=290)
- 当前个人价格表列出：实时日线 200 元／月，实时分钟 1000 元／月，历史分钟 2000 元／年。这里只作方案成本参考，尚未购买或验证账号权限。[权限与频次表](https://tushare.pro/document/1?doc_id=290)
- `daily` 是收盘后入库的未复权日线，停牌期间不提供记录；不能代替盘中行情。[A 股日线文档](https://tushare.pro/document/1?doc_id=27)
- `rt_k` 提供当日实时日 K 截面，单次最多 6000 条，需独立权限；成交量单位为股，并可选择返回交易时间。它不是分钟序列接口。[实时日线文档](https://tushare.pro/document/2?doc_id=372)

**方案推论**：Tushare 可列作候选替换源，但接入适配层必须统一股／手等单位，区分实时截面与已收盘历史数据。免费日线不满足完整盘中能力。具体账号频次、延迟、交易时间字段可用性及所需权限应在接入验证阶段确认。

## 3. Android：后台预警不能依赖高频本地定时器

- WorkManager 周期任务最小间隔为 15 分钟；执行时间受系统优化、约束和调度影响，不是准确时钟。[工作请求文档](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)
- Doze 会限制网络并推迟任务，WorkManager 也受影响。官方建议下行消息使用推送机制，并对需要向用户展示的及时消息讨论高优先级推送。[Doze 与 App Standby](https://developer.android.com/training/monitoring-device-state/doze-standby)
- Android 13 及以上普通通知需要 `POST_NOTIFICATIONS` 运行时权限；拒绝后不能把普通通知视为可用提醒渠道。[通知权限文档](https://developer.android.google.cn/develop/ui/compose/notifications/notification-permission?hl=en)

**方案推论**：如要求 APP 关闭后仍监控行情，采用持续在线服务端计算条件、记录触发事件，再通过适配目标手机的推送渠道通知。WorkManager 负责补同步等可延迟工作。服务端触发成功与手机收到通知是两个独立状态，产品应分别记录，不能宣称消息必达。

**真机验证项**：用户手机品牌及系统版本、推送渠道与网络可达性、通知权限关闭、锁屏、Doze、APP 被划走、被系统回收、强制停止、断网重连。记录各场景触发时间与送达时间；由实测决定延迟目标与降级提示，不预先保证秒级送达。

## 4. 对第一版范围的建议

先以已收盘日 K 完成指标筛选与 AI 比较，建立可重复的数据快照；盘中图表与预警依数据源和推送验证结果逐步开放。这是实施建议，不是已确认的需求削减。AI 所用事实必须带来源与时间；数据缺失时明确缺失，不把模型结论当作指标收益证明。
