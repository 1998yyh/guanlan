# 观澜交互原型 V3

2026-09-12：深色方案，首页与策略库保留；复盘合并进聊天。

## 打开

在项目根运行 `python3 -m http.server 4174 --bind 127.0.0.1 --directory prototype`，访问 http://127.0.0.1:4174/ 。也可直接打开 index.html。

## 本轮体验

底部为看盘、选股、观察、AI 复盘。进入 AI 复盘可以直接聊天，或选择大盘/个股复盘任务，选择对象和日期后发送。消息区域独立滚动，输入栏停留在底部。

右上角“＋”新建对话，“记录”打开历史；可恢复旧会话继续交流，删除前确认。未发送的空新会话不写入历史；已有会话的输入草稿本机保存。观察池个股复盘和个股详情会打开带对象的新对话；选股比较可继续讨论。

自定义策略保存在 `guanlan-PROTOTYPE-strategies-v2`，聊天历史保存在 `guanlan-PROTOTYPE-conversations-v3`。仅当前浏览器/站点可用，清理浏览器数据或确认删除会丢失；不是正式备份与同步方案。刷新和重置临时演示保留已保存策略与对话，观察和预警模拟仍刷新清空。

## 演示边界

所有行情、指标、筛选结果与回复均为固定样例，没有连接真实 AI、行情或推送。复盘日期标记会话，样例行情日期固定为 2026-09-10。自定义策略是内置指标组合，尚不支持公式。

原型只验证交互，不扩展正式业务代码。当前设计待用户评审。

## 验证

浏览器检查覆盖新建大盘/个股会话、多轮消息、刷新后恢复历史、取消删除、确认删除及旧会话继续发送；375/393/768/1440 宽度下检查横向溢出与发送按钮可见性。尚未验证安卓真机软键盘行为和真实模型能力。
